# AFTERFALL

**A realism-focused post-apocalyptic survival FPS that runs entirely in your browser.**

Eight years after the bombs fell, you climb out of a shelter into a silent, irradiated Korea.
Find out who else is still alive — and what really happened at ground zero.

▶ **Play:** https://oblocko.github.io/afterfall/

## Features
- **Hardcore survival:** health, stamina, hydration, food, radiation dose, bleeding and limb injuries
- **Realistic gunplay:** iron sights and optics, bullet travel and drop, penetration and ricochets, weapon wear and jams
- **Tactical enemies:** they take cover, flank, suppress you and push in when you reload
- **Looting and inventory:** weight-based carrying, stacking, containers, crafting and trading
- **Dynamic world:** day/night cycle, weather, radiation storms, random events
- **Story quests:** radio signals, a military radar base, a radiation research lab and more
- **Sandbox and test maps:** a training ground plus a dev-grid map for trying out every weapon and item
- **Auto graphics scaling:** low-spec devices automatically switch to lighter models

## Controls (default)
| Key | Action |
|---|---|
| WASD | Move |
| Shift | Sprint |
| Ctrl / C | Crouch |
| X | Prone |
| Q / E | Lean |
| F | Interact |
| R | Reload |
| Tab | Backpack (E use · Q drop) |
| J | Journal |
| B | Crafting |
| L | Flashlight |
| 1–4 | Weapon slots |

All keys can be remapped in Settings.

## Requirements
A desktop browser with WebGL 2 (Chrome, Edge or Firefox recommended).
On weaker devices the game lowers its graphics automatically.
